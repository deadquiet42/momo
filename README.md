# MOMO

A small electronic creature that lives in your handheld. It notices you, reacts, chatters in a voice of its own, dozes, dreams and remembers you between visits. Every MOMO is different.

One Python file, SDL2 only. The eyes are drawn and the voice is synthesised live; there are no assets.

Download: https://deadquiet42.github.io/momo/

## Run

Python 3.11 or later with the SDL2 library installed:

```
python3 momo_app.py [save directory]
```
